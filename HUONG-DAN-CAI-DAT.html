0 Bộ cài gồm những gì

  • index.html — Ứng dụng quản lý quỹ (bản để đưa lên hosting).
  • app_quy_tapaco.html — Bản 1 file để xem/chạy thử nhanh (nằm ngoài gói zip).
  • Code.gs — Mã backend dán vào Google Apps Script (đồng bộ Sheet + ảnh Drive).
  • manifest.webmanifest, sw.js — Giúp cài như app thật, chạy offline, tự cập nhật.
  • icon-192.png, icon-512.png — Biểu tượng TAPACO Money.
  • app.txt — Chứa URL Apps Script để app tự lấy (xem Phần 2).
  • HUONG-DAN-CAI-DAT.html — File này.
Có 3 "mảnh" cần ghép: (A) Backend trên Google — Sheet + Apps Script; (B) App — đưa lên link https; (C) Thư mục ảnh trên Drive. Làm lần lượt theo các phần dưới.

1 Dựng Google Sheet + Apps Script

Làm 1 lần trên 1 tài khoản Google của công ty (khuyến nghị vuhuylong1976@gmail.com hoặc tài khoản quản trị).
1. Vào sheets.new tạo 1 Google Sheet mới. Đặt tên, ví dụ "TAPACO - Quỹ (Dữ liệu)". Đây là kho dữ liệu dùng chung.
2. Trên Sheet: menu Tiện ích mở rộng → Apps Script.
3. Xóa hết nội dung mẫu, dán toàn bộ nội dung file Code.gs vào, bấm 💾 Lưu.
4. Bấm Triển khai (Deploy) → Tùy chọn triển khai mới → Loại: Ứng dụng web (Web app).
  • Thực thi với tư cách: Tôi (Me)
  • Người có quyền truy cập: Bất kỳ ai (Anyone)
5. Bấm Triển khai. Google sẽ hỏi cấp quyền (Authorize) — chọn tài khoản, bấm "Nâng cao → Đi tới … (không an toàn)" → Cho phép. (Cần quyền Sheet + Drive để lưu ảnh.)
6. Sao chép URL Web app (kết thúc bằng /exec). Đây là URL đồng bộ của app.
Xong Phần 1. Giữ lại URL …/exec — sẽ dùng ở Phần 2.
Mỗi lần sửa Code.gs về sau đều phải Triển khai lại (Deploy → Quản lý triển khai → ✏️ → Phiên bản: Mới). URL /exec giữ nguyên nếu dùng "Quản lý triển khai"; nếu tạo triển khai mới sẽ ra URL mới (khi đó cập nhật app.txt ở Phần 2).

2 Thư mục ảnh & file app.txt

2.1 — Thư mục chứa ảnh chứng từ

Mọi ảnh chứng từ (mọi tài khoản nhập) sẽ được đẩy về một thư mục Google Drive cố định, đặt tên theo số chứng từ.

  • Trong Code.gs, dòng var PHOTO_FOLDER_ID = '…'; là ID thư mục ảnh.
  • Lấy ID: mở thư mục trên Drive, nhìn thanh địa chỉ drive.google.com/drive/folders/ID_Ở_ĐÂY → copy đoạn ID.
  • Thư mục phải nằm trong Drive của chính tài khoản chạy script, hoặc được chia sẻ quyền Chỉnh sửa cho tài khoản đó.
Tên ảnh tự đặt dạng CT_<mã quỹ>_<số chứng từ>__<mã bản ghi>.jpg nên mở lại luôn truy xuất đúng ảnh của từng chứng từ. Sheet có thêm tab Anh_ChungTu liệt kê Số CT · Quỹ · Ngày · link Drive.

2.2 — File app.txt (để đổi URL không phải sửa từng máy)

Khi mở app, app tự đọc URL Apps Script từ app.txt. Đổi URL sau này chỉ cần sửa 1 file này.

  • Mở app.txt, thay bằng URL …/exec ở Phần 1 (một dòng), lưu lại.
  • Đặt app.txt cạnh index.html trên hosting (Phần 3) → app đọc tự động. Cách chắc ăn nhất
Về link Google Drive cho app.txt: trình duyệt thường chặn JavaScript tải file từ Drive (bảo mật CORS), nên để app.txt trên Drive hay không đọc được. Nếu muốn đặt ngoài hosting, nên dùng GitHub raw (chạy mọi nơi). Nếu app không tự đổi URL, app vẫn dùng URL đang lưu — không hỏng.

3 Đưa app lên mạng (link https)

App chỉ cài được như ứng dụng thật và tự cập nhật khi mở qua đường dẫn https. Mở bằng file trực tiếp chỉ xem được.

Cách nhanh nhất — Netlify Drop Miễn phí, 1 phút

1. Mở app.netlify.com/drop trên máy tính.
2. Kéo-thả nguyên thư mục tapaco-quy-app vào trang → nhận link dạng https://ten-ngau-nhien.netlify.app.
3. Mở link đó trên điện thoại/máy tính để cài (Phần 4).
Muốn link cố định, tên đẹp: tạo tài khoản Netlify miễn phí → Site settings → Change site name.

Cách link cố định — GitHub Pages

1. Tạo tài khoản github.com, tạo repository (Public), ví dụ tapaco-quy.
2. Add file → Upload files: tải lên tất cả file trong thư mục (index.html, sw.js, manifest.webmanifest, app.txt, 2 icon).
3. Settings → Pages: Branch main + /root → Save. Sau 1–2 phút có link https://<tên>.github.io/tapaco-quy/.

4 Cài trên điện thoại & máy tính

📱 iPhone / iPad (Safari)

  1. Mở link https bằng Safari.
  2. Bấm Chia sẻ ⎙ → Thêm vào MH chính → Thêm.

📱 Android (Chrome)

  1. Mở link https bằng Chrome.
  2. Bấm nút 📲 Cài app trong app, hoặc menu ⋮ → Cài đặt ứng dụng.

💻 Windows / Mac (Chrome / Edge)

  1. Mở link https.
  2. Bấm 📲 Cài app trong app, hoặc biểu tượng cài ⊕ cuối thanh địa chỉ.
→ Mở từ biểu tượng TAPACO Money, chạy full màn hình, không có thanh địa chỉ, dùng được cả khi mạng yếu.

5 Chạy lần đầu

1. Mở app, đăng nhập admin / admin123 (đổi mật khẩu sau).
2. Vào Tài khoản → Cài đặt đồng bộ: kiểm tra URL đã đúng (nếu dùng app.txt thì tự nhận). Bấm ⬇ Tải từ Sheet để lấy dữ liệu dùng chung.
3. Tạo Quỹ (công trường/văn phòng) và Tài khoản cho từng bộ phận ở tab Danh mục / Tài khoản.
4. Trên Google Sheet: tải lại trang để hiện menu 📷 Ảnh chứng từ → bấm Bật tự động (mỗi giờ) (lần đầu hỏi cấp quyền → Cho phép). Nếu có ảnh cũ, bấm Gom ảnh cũ… một lần.
Mỗi công trường: mở app → đăng nhập → vào Sổ quỹ → bấm ☁ Đẩy ảnh lên Drive để đưa ảnh đã nhập trước đó lên thư mục chung.

6 Phân quyền & tính năng chính

Phân quyền

Vai tròLàm được gì
AdminToàn quyền; riêng Admin sửa được link URL đồng bộ.
Kế toánXem & sửa số liệu toàn công ty; chỉ thêm/sửa tài khoản Công trình & Văn phòng; không đụng tài khoản Admin & link URL.
Công trình / Văn phòngLàm việc trên bộ phận được giao (Tổng quan · Sổ quỹ · Báo cáo); xem Danh mục; thêm được Đối tượng.

Các tính năng

  • Nhập thu/chi: số chứng từ tự đề xuất, định dạng số sống, chụp/tải ảnh chứng từ (tự lên Drive).
  • In phiếu Thu/Chi mẫu Bộ Tài chính (Mẫu 01-TT / 02-TT, đủ 5 cột ký, số tiền bằng chữ).
  • Sổ quỹ: cột Đối tượng, ô tìm kiếm (đối tượng/diễn giải/khoản mục), bấm tiêu đề để sắp xếp, mặc định ngày mới nhất.
  • Báo cáo: lọc theo kỳ / quỹ / đầu mục / khoản mục / đối tượng, biểu đồ, ô tìm kiếm chi tiết, xuất Excel & PDF.
  • Ngưỡng cảnh báo chi (Danh mục): Admin đặt ngưỡng (vd chi ≥ 20 triệu phải chuyển khoản; lương tiền mặt > 5 triệu) — app cảnh báo hoặc chặn khi nhập.
  • Cỡ chữ: nút A Vừa/To/Nhỏ trên đầu app, nhớ theo từng máy.
  • Đồng bộ 2 chiều Google Sheet mỗi phút; cài được như app, chạy offline.

7 Cập nhật phiên bản sau này

  • Sửa giao diện/tính năng app: thay index.html (và sw.js nếu có bản mới) trên hosting → các máy tự nhận sau khi mở lại. Không cài lại.
  • Sửa backend (Code.gs): dán lại vào Apps Script → Triển khai lại (phiên bản mới).
  • Đổi URL Apps Script: chỉ sửa app.txt (nếu app đọc được app.txt), hoặc vào Tài khoản → Cài đặt đồng bộ dán URL mới.
